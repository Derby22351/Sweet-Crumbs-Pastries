📖 About the Project

Sweet Crumbs Pastries is a front-end web development project designed to showcase a bakery's products through a visually appealing landing page. The website features a welcoming hero section, pastry categories, product cards, and navigation designed to provide a pleasant browsing experience.

This project is part of my web development portfolio and demonstrates my skills in building and styling websites with HTML and CSS.

✨ Features

- Responsive landing page design
- Bakery branding and navigation header
- Hero section with a call-to-action button
- Pastry categories and product cards
- Product images and pricing
- Search and shopping cart interface
- Mobile-friendly layout

Note: Interactive features may still be under development.

🛠️ Technologies Used

- HTML5
- CSS3
- Font awesome for interface icons

🚀 Getting Started

1. Clone or download this repository.
2. Open the project folder in your code editor.
3. Open "index.html" in your browser to view the website.

No additional installation is required for the basic static website.

🌍 Deployment

This project can be hosted for free using GitHub Pages.

1. Push the project files to a GitHub repository.
2. Open the repository's Settings.
3. Select Pages.
4. Choose the "main" branch and the root folder.
5. Save and visit the published website URL.
